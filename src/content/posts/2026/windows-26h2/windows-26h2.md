## Windows 26H2 Update Highlights

### Taskbar & Start Menu Customizations

* **Movable & Small Taskbar:** Reintroduced support for repositioning the taskbar (such as placing it at the top of the screen) and a dedicated "Small Taskbar" mode.
* **Resizable Start Menu:** Improved layout customization options and a cleaner "Recent" items section.
* **App-Specific Taskbar Actions:** Quick access to common operations directly from taskbar hover menus and jump lists.


### Windows Search & File Explorer Improvements

* **Local-Only Search:** Added a toggle to disable Bing web results and Microsoft Store suggestions in Windows Search.
* **Accurate Storage Units:** File Explorer now displays exact file size metrics (KB, MB, GB) clearly across all views.
* **Context Menu Tweaks:** Streamlined and customizable right-click context menu with lower latency and faster response times.


### Security & Administrator Enhancements

* **Administrator Protection:** Uses just-in-time administrative privileges and profile separation (via Windows Hello) to harden against elevation-of-privilege attacks.
* **Smart App Control Toggle:** Can now be switched on or off at any time without requiring a clean installation of Windows.
* **Built-in Sysmon:** Integrated native System Monitor functionality for advanced event logging and threat detection (off by default).
* **External Biometrics Support:** Expanded Windows Hello Enhanced Sign-in Security for external cameras and peripheral fingerprint readers.


### AI & Settings Integration

* **Agents in Settings:** Added natural-language AI search inside the Settings app to locate and toggle system configurations faster.
* **Task Manager AI Monitoring:** Expanded diagnostics to track AI workloads and dedicated NPU activity.
* **Ask Copilot Integration:** Optional taskbar integration for finding local files, changing settings, and launching apps.


### Performance, Recovery & Hardware

* **Enablement Package (eKB):** Delivered as a lightweight update for systems running 24H2 or 25H2, enabling a fast installation with a single restart.
* **Memory & UI Optimizations:** Reduced RAM footprint and faster responsiveness when opening the Start menu, Settings, and apps.
* **Point-in-Time System Recovery:** Upgraded Cloud Rebuild and recovery options with native Wi-Fi support inside the Windows Recovery Environment (WinRE).
* **Multi-App Camera Support:** Allows multiple applications to access a webcam stream simultaneously.
* **Bluetooth & USB4 Reliability:** Improved stability for Bluetooth LE Audio and external displays connected via USB4 docks after waking from standby.
